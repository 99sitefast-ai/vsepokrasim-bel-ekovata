## Что стоит проверить и заменить своими данными

1. **Цены** — в `tseny.html` (таблица) и `index.html` (краткий блок), а также ставки в
   `assets/js/app.js` в объекте `RATES` (BYN за м² при 100 мм и плотность кг/м³).
   Сейчас там ориентировочные значения, их нужно привести к своим.
2. **Цифры на главной** — «1–2 дня», «до 30%», «50 м шланг». Если у вас другие, поправьте.
3. **География выезда** — `kontakty.html` и подвал.
4. **График работы** — «Пн–Сб, 8:00–20:00» в подвале всех страниц.
5. **Реквизиты** — если нужно, добавьте ИП/УНП и юридический адрес в подвал.
6. **Фотографии** — сейчас в `assets/img/` лежат сгенерированные изображения под тему
   (задувка, чердак, кровля, стена, оборудование, волокно, дом). Замените их своими
   фотографиями с объектов с теми же именами файлов — вёрстка подстроится сама.
   Рекомендуемый размер: 1600 px по длинной стороне, JPEG q80.

## Публикация на GitHub Pages

1. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, папка `/ (root)`.
2. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
3. Для своего домена: Settings → Pages → Custom domain, затем в DNS прописать CNAME
   на `<логин>.github.io`.

Файл `.nojekyll` уже добавлен, чтобы GitHub не трогал статику.
